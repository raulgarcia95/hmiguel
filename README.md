# La herencia del Tío Miguel

Aventura gráfica clásica adaptada a Canvas 2D, con ilustraciones HD, música, inventario, conversaciones y guardado local.

## Jugar

https://raulgarcia95.github.io/hmiguel/

Pulsa **Comenzar aventura**. Clic para caminar o interactuar; **Mirar** para examinar; selecciona objetos del inventario para utilizarlos. Clic derecho cambia entre mirar y mano. **Esc** suelta el objeto. **Intro** continúa los textos. **Guardar / Cargar** conserva la partida en este navegador.

El juego llena la ventana sin deformar sus escenarios. **Pantalla completa** oculta la interfaz del navegador. La introducción da paso a la portada durante diez segundos, con fundidos. Las conversaciones se sobreimprimen sobre la ilustración.

## Estado y fidelidad

33 escenarios y 12 retratos HD, máscaras originales, nueve secuencias y 16 músicas. Las animaciones se reconstruyen con fotogramas clave y capas; no son un redibujo individual idéntico de cada fotograma original. Los programas del televisor conservan sus imágenes originales.

El material original contiene dos destinos sin habitación (0 y 24), un condicional sin terminar en la tienda de deportes y una canción ausente (3D.MOD). La adaptación informa de estos casos; no inventa contenido para ocultarlos. La verificación automatizada no equivale a una partida completa de principio a fin.

## Desarrollo

Sitio estático: servir esta carpeta con cualquier servidor HTTP. No requiere cuentas, servidor de datos ni dependencias externas. El guardado permanece en el navegador del jugador.
